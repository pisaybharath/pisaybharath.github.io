# Portfolio

Personal portfolio of Bharath Pisay. A static site with no build step: `index.html`, `styles.css` and `script.js`, with the fonts self-hosted in `fonts/`.

Open `index.html` in a browser to preview it. It is published with GitHub Pages from the `main` branch.

The fonts, Bricolage Grotesque and Source Serif 4, are licensed under the SIL Open Font License (see `fonts/`).
